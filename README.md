# Travel Agency Page ✈️🌴

A structured, responsive travel destination webpage built as part of my frontend software development course.

## 🚀 Features
* **Semantic HTML5 Structure:** Built using proper semantic elements (`head`, `body`, `h1`, `h2`, `p`, `ul`, `figure`, `figcaption`).
* **SEO Optimization:** Includes charset declaration and a customized meta description tag for search engine indexing.
* **Curated Packages & Top Itineraries:** Features organized lists for Group Travels and Private Tours alongside image-rich destination cards.
* **Accessible Navigation:** All images include descriptive `alt` text and are wrapped in external links configured to open safely in new tabs (`target="_blank"`).
